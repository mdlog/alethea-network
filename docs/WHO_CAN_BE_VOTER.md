## 📊 How Selection Works

### Important: Registration ≠ Guaranteed Selection

**Everyone can register, but not everyone votes on every query.**

### Selection Process:

**1. Anyone Can Register** ✅
```
Alice registers: 1,000 stake × 50 rep = 50,000 power
Bob registers: 15,000 stake × 50 rep = 750,000 power
Carol registers: 10,000 stake × 50 rep = 500,000 power
... anyone else can register too!
```

**2. Selection by Power** 🎯
```
When query created (min 3 votes needed):
- System selects top 6 voters by power
- Bob (750k power) → Selected ✅
- Carol (500k power) → Selected ✅
- Dave (400k power) → Selected ✅
- Eve (250k power) → Selected ✅
- Frank (200k power) → Selected ✅
- Grace (150k power) → Selected ✅
- Alice (50k power) → Not selected ❌
```

**3. Only Selected Voters Can Vote** 🗳️
```
Bob can vote ✅
Alice cannot vote on this query ❌
(But Alice can be selected for other queries!)
```

## 🔐 Security Considerations

### Sybil Resistance

**Q: Can someone create 1,000 accounts with 100 tokens each?**

**A: Yes, but it won't help!**

**Why:**
```
1,000 accounts × 100 tokens × 50 rep = 5,000,000 total power

But selection is per-account:
- Each account: 100 × 50 = 5,000 power
- Very low selection chances
- Not economically viable

Better strategy:
1 account × 100,000 tokens × 50 rep = 5,000,000 power
- High selection chances
- Better rewards
- More efficient
```

**Conclusion:** System naturally discourages sybil attacks through power-based selection.

## 📝 Registration Process

### How to Register:

**Option 1: Via Dashboard (Easiest)**
```
1. Open http://localhost:4000/voters
2. Connect wallet
3. Fill form:
   - Stake: 1000 (or more)
   - Name: Alice (optional)
4. Click "Register"
5. Wait for confirmation
6. Done! You're a voter ✅
```

**Option 2: Via Backend API**
```bash
curl -X POST http://localhost:3001/api/transaction/register-voter \
  -H "Content-Type: application/json" \
  -d '{
    "voter_address": "0x1378...",
    "stake": "1000",
    "name": "Alice"
  }'
```

**Option 3: Via GraphQL (Advanced)**
```graphql
mutation {
  registerVoter(
    stake: "1000",
    name: "Alice"
  )
}
```
