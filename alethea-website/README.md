# Alethea Network Website

Official website for Alethea Network - Decentralized oracle platform built on Linera Protocol.

## Features

- 🎨 Modern design with Tailwind CSS
- ⚡ Next.js 14 with App Router
- 🎭 Smooth animations with Framer Motion
- 📱 Fully responsive
- 🌙 Elegant dark theme

## Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## Access Website

Development: http://localhost:3001
