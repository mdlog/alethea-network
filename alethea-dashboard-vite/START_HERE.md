# 🚀 Quick Start - Email Reminder System

## ✅ Status: CONFIGURED & READY

Email: **notifications@alethea.network** (Hostinger)

## 3 Langkah Mudah:

### 1️⃣ Install
```bash
npm install
```

### 2️⃣ Test Email (Optional)
```bash
# Test koneksi SMTP
npm run test:email

# Atau kirim test email ke email Anda
npm run test:email your-email@example.com
```

### 3️⃣ Start
```bash
npm run dev:all
```

Buka: http://localhost:5173

## 🎯 Cara Pakai:

1. Klik tombol **"Remind me"** di homepage
2. Masukkan email
3. Pilih waktu reminder
4. Done! ✅
