## 📊 Email Features:

### Commit Phase Email:
- 🔒 Blue theme (trust, security)
- Clear call-to-action: "Vote Now"
- Explanation of commit phase
- Reminder to return for reveal phase
- Time remaining countdown

### Reveal Phase Email:
- 👁️ Amber/Orange theme (urgency, warning)
- Clear call-to-action: "Reveal Vote Now"
- Warning about penalties
- Explanation of reveal phase
- More urgent tone

### Common Elements:
- ✅ Professional Alethea branding
- ✅ Responsive design (mobile & desktop)
- ✅ Query details with source
- ✅ Time remaining countdown
- ✅ Phase explanation
- ✅ Direct action button
- ✅ Footer with links
- ✅ Unsubscribe option
