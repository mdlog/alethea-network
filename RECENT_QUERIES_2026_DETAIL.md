# 📋 Query Peristiwa Terbaru (Januari 2026 & Akhir 2025)

## ⚙️ Konfigurasi Query

- **Commit Duration**: 12 jam (43,200 detik)
- **Reveal Duration**: 12 jam (43,200 detik)
- **Total Duration**: 24 jam (86,400 detik)
- **Strategy**: WeightedByStake
- **Min Votes**: 3
- **Reward**: 100 ALTH

## 📐 Struktur Query (Profesional)

Setiap query memiliki field terpisah:

| Field | Deskripsi | Contoh |
|-------|-----------|--------|
| **Title** | Judul pendek, ringkas | "Bitcoin Mencapai $100K di 2025" |
| **Description** | Pertanyaan utama yang jelas | "Apakah harga Bitcoin (BTC) mencapai atau melampaui $100,000 USD pada tahun 2025?" |
| **Context** | Latar belakang dan informasi pendukung | "Bitcoin mengalami bull run signifikan di 2024-2025..." |
| **Resolution Criteria** | Kriteria spesifik untuk resolusi | "Resolusi berdasarkan data harga dari CoinGecko..." |
| **Source URLs** | Link rujukan untuk verifikasi | "https://www.coingecko.com/en/coins/bitcoin, ..." |
| **Category** | Kategori query | "Kripto" |
| **Outcomes** | Pilihan jawaban | ["Ya", "Tidak"] |

## 📝 Catatan

- Query dengan peristiwa yang **sudah terjadi** (Trump inauguration, Super Bowl LIX) bisa langsung di-resolve
- Query dengan peristiwa **belum terjadi** (Champions League 2025, NBA Finals 2025) harus menunggu hingga event selesai
- Semua query memiliki sumber rujukan yang jelas untuk memastikan resolusi yang akurat
